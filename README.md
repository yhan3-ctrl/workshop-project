# Project workspace

This workspace contains two short project activities. The facilitator will tell
you which activity to open. Please approach each activity as you normally would
on a comparable project, within the session time available. Let the facilitator
know when you consider the activity complete.

## Tools

You may use GitHub Copilot in the editor or Gemini CLI in the terminal, whichever
you are comfortable using and have access to. Use Copilot's Agent mode for an
activity that requires file changes. To open Gemini CLI, enter `gemini` in a
terminal. Sign-in or account access may be required. Ask the facilitator for
setup help if needed.

## Activities

- [Project handoff](tasks/task1.md)
- [Settings utility](tasks/task2.md)

## Environment

The project files are supplied examples in a GitHub Codespace, not files copied
from your own project. Editing these files changes this workspace. A Codespace
does not automatically include files on your computer. Connected accounts and
external services retain their own permissions; do not connect additional data,
credentials, or services for these activities. The facilitator will explain the
recording and privacy arrangements before the session.
